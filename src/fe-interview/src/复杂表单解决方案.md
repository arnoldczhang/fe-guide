# 复杂表单解决方案

## 核心理念
- 状态集中管理
- 视觉和逻辑解耦
- 体验优化
- 可维护性

## 状态集中管理
- 派发更新 + 组件树
- 顶层组件提供数据变更的方法，统一管理状态（context）

## 视觉和逻辑解耦
- 用hook抽象逻辑处理
- 视觉层对接UI框架，调用hook

## 体验优化
- 异步校验
- 组件缓存（React.memo）
- 无障碍

## 可维护性
- 按领域模型做模块拆分
- 配置驱动（formly）
- 模块遵循分层架构模式
  > components
  > hooks
  > schema
  > context
  > utils
