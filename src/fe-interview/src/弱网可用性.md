# 弱网可用性

## 1. 资源加载优化
- 懒加载（css/js资源、图片）
- 预加载（preload/prefetch）
- 资源压缩（webp/gzip/brotli）
- 缓存（200&304/pwa）

## 2. 交互优化
- 请求优化（防抖节流、请求优先级）
- 离线队列（监听offline事件、数据暂存本地）
- 静默加载（预测用户下一步行为，预先加载资源）

## 3. 数据优化
- 按需加载（分页、虚拟滚动）
- 高效数据格式（protobuf）

## 4. 反馈优化
- 加载特效（百分比loading、骨架屏）
- 重试机制（指数退避算法）
- 错误提示（原因、解决，清晰明确）
- 优雅降级（img失败兜底、功能隐藏/禁用）
- 统一离线/错误页面
