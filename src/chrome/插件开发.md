## manifest V3

### permission
- storage
- tabs
- clipboardRead
- clipboardWrite
- unlimitedStorage

V3移除了webRequest，所以需要代理请求方法（fetch、XMLHttpRequest），有[现成库](https://github.com/jpillora/xhook)的

### 配置项

```js
{
  /** 常驻后台页 */
  background: {
    service_worker: 'xxx',
    type: 'module',
  },
  /** 右上角工具图标 */
  options_page: 
  /** 开发者工具 */
  devtools_page: 
  /** 当前页面运行的脚本 */
  content_scripts: {},
  /** 工具图标（不同尺寸） */
  icons: {},
}
```
