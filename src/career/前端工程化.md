# 前端工程化

> 本质是人的系统工程

## 总纲
围绕开发效率、代码质量、协同合作、性能优化、CICD这五块展开

## 开发效率
- 模块化（基于业务做领域拆分、monorepo）
- 组件化（视图 + hook拆分）
- 初始化脚手架（commander、inquirer）

## 代码质量
- 代码规范（eslint、stylelint）
- 格式化（prettier）
- git message规范
- husky（pre-commit、pre-push）
- sonaqube（代码健康度）

## 协同合作
- git命令行工具
- 项目组件预览（vuepress/storybook）
- 项目文档、技术文档

## 性能优化
- 围绕构建工具展开（webpack、vite）
- 拆包懒加载
- treeshake
- 资源压缩（uglify、postcss、图片转webp）
- 增量更新（contenthash + 200强缓存）
- 性能指标（FCP、CLS、FID）

## CICD
- CI：github action（代码提交 -》 运行单元测试 -》 代码规范检查 -》 构建 -》 生成产物）
- CD：产物部署测试环境 -》预发环境 -》 灰度发布 -》 上线
