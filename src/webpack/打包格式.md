# 打包格式

|     | 规范   | 语法             | 优点                  | 缺点   |
| --- | ---- | -------------- | ------------------- | ---- |
| amd | 社区规范 | define/require | 适合浏览器通过require.js加载 | 语法繁琐 |
| cmd | 社区规范 | define/require | 语法接近node.js         | 语法繁琐 |
| umd | 通用规范 | 立即执行函数/挂载全局变量  | 兼容性最好               | 代码丑陋 |
| esm | 官方规范 | import/export  | 未来趋势，树摇基础，异步加载      | 兼容性  |



## package.json

```js
{
  "main": "./dist/index.cjs.js", // 用于 CommonJS/Node.js
  "module": "./dist/index.esm.js", // 用于支持 ESM 的打包工具
  "unpkg": "./dist/index.umd.js", // 用于 CDN 的默认文件
  "types": "./dist/types/index.d.ts", // 类型声明文件
  "exports": {
    ".": {
      "import": "./dist/index.esm.js", // ESM
      "require": "./dist/index.cjs.js", // CommonJS
      "default": "./dist/index.esm.js"
    }
  }
}
```
