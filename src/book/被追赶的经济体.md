# 被追赶的经济体

## 一、宏观经济

### 资产负债表衰退

1. 资产因泡沫破裂而缩水，用户优先考虑还贷而非再投资，导致经济通缩
2. 住建部门借贷减少，私人储蓄增加

### 量化宽松陷阱

开启时，购入大量债券；退出时，降价抛售债券，债券收益率上升，股市可能崩盘。

### 通缩螺旋

收入↓ -》消费降级 -》经济下行 -》收入↓ ，直至收缩性均衡

### 合成谬误

- 微观行为的总和≠宏观行为，甚至导致相反的结果

- 资产负债表衰退阶段，私人行为不再以利润最大化为优先考虑项

### 日本经济失败原因

- 错误的控制赤字上限（经济发展停滞 -> 税收减少 -> 赤字扩大）

- 错误的上调消费税（税率↑ -> 消费减少&降级 -> 税收总量下降 -> 赤字扩大）

### 最后借款人

- 当私人部门不借贷时，政府部门必须充当最后借款人（即使财政乘数算不清）

- 托底旧经济的前提下，大力发展新经济

**财政乘数效应**

每投入1单位货币，产生的GDP增长

## 二、经济发展三阶段

- 城镇化经济

- 成熟经济体

- 被追赶的经济体

### 城镇化经济

- 城镇岗位 <<< 农村富余劳动力

- 精英阶级赚取绝大部分收益

### 成熟经济体

- 刘易斯拐点后（农村劳动力短缺）

- 工人具有更强的议价能力

### 被追赶的经济体

- 资本为追求更高的回报率，低端产业转移国外
- 本国各阶级工资增速降低，低端劳动者尤甚

**思考**

随着ai的发展，前端也进入了“被追赶的经济体”阶段，明显的特征就是：
1. 前端议价能力下降，ai替代简单劳力，行业人口饱和
2. 投资回报的边际效应持续降低，导致公司谨慎式招人
