# 被追赶的经济体

## 一、宏观经济

### 资产负债表衰退

1. 资产因泡沫破裂而缩水，用户优先考虑还贷而非再投资，导致经济通缩
2. 住建部门借贷减少，私人储蓄增加

### 量化宽松陷阱

开启时，购入大量债券；退出时，降价抛售债券，债券收益率上升，股市可能崩盘。

### 通缩螺旋

收入↓ -》消费降级 -》经济下行 -》收入↓ ，直至收缩性均衡

### 节俭悖论

- 如果每个人都想储蓄，最终就会由于没人借贷而达不到储蓄目标

- 推导出合成谬误

### 合成谬误

- 微观行为的总和≠宏观行为，甚至导致相反的结果

- 资产负债表衰退阶段，私人行为不再以利润最大化为优先考虑项

### 日本经济失败原因

- 错误的控制赤字上限（经济发展停滞 -> 税收减少 -> 赤字扩大）

- 错误的上调消费税（税率↑ -> 消费减少&降级 -> 税收总量下降 -> 赤字扩大）

### 最后借款人

- 当私人部门不借贷时，政府部门必须充当最后借款人（即使财政乘数算不清）

- 托底旧经济的前提下，大力发展新经济

**财政乘数效应**

每投入1单位货币，产生的GDP增长

### 企业借款

- 住房部门借款，终将流入金融市场
- 非银借款才有可能流入实体经济

### 储蓄和债务

- 债务永远不会大于储蓄

- 重复借贷，最后花掉的还是最初借贷额，而非累加值

- 能收支平衡（本身盈利 + 正外部性）的债务，不用担心

- 能拉动的GDP超过债务本身 + 利息支出，也不用担心

- 实在没事可做，只要能拉动经济，都能先做？

- 债券价格（借条价格）↓ -> 借贷成本↑ -> 债券收益率↑

## 三、经济如何持续增长

> 持续创造消费者“必须拥有”的产品

### 持续增长（企业）

1. 预测新的爆款

2. 降本

**全要素生产力**

所有生产要素（土地、能源、人力）的投入量不变的情况下，产出增加的部分。

**中等收入陷阱**

约等于被追赶的经济体阶段

### 持续增长（被追赶的经济体）

1. 供给侧改革（减税、放松管制 --> 提升资本回报率）

2. 鼓励劳动力市场提高灵活性（抵御追赶者）

3. 教育系统改革（个性化教育，不断满足特定领域的人力需求）

其中，1和2可以事中做，但是3需要有预见性地提前做。

### 供给侧改革

> 参考国策：三去一降一补

1. 淘汰落后产能

2. 降本

3. 补短板

4. 优化资源配置
