# 重组与突破

重组：资本金注入夯实了融资信用基础
退二进三：第二产业搬迁郊区，主城区让给第三产业
汇金：作为第三方，兜底银行间的历史遗留问题

## 重组三招

- 股权重组（引入私人资本，抬高股价）
- 资产重组（政府替身公司注资，三级架构）
- 债务重组（坏债打包，土地抵债，降本提效）

## 经济运行衡量

- 资金融通
- 交通畅通
- 商贸流通

## 国有资产

- 国有资本投资公司 - 成长
- 国有资本运营公司 - 价值

### 国有资本运营公司

- 投资不控股（参股类股权投资，给钱不参与实际运营）
- 有股权不并表（仅监控财务状况）
- 有资产不负债（仅以实际资本金投资）

### 国有资本投资公司

- 三级架构（集团总部、二级公司、三级企业）
  - 集团总部（战略决策）
  - 二级公司（技术创新）
  - 三级企业（生成经营）
- 低杠杆
- 信息透明
- 合理的资本流动性

### 民营企业

- 寄希望于上市解决融资问题，大环境不好就是割韭了

### 房地产

- 一万人对应一平方公里的城市建成面积
  - 基础、公共设施占50-55%
  - 工业用地15-20%
  - 房产25-30%
- 合理的房价 = 3倍地价 = 1/3地价 + 2/3造价
- 普通人不得不以确定性换确定性
- 地票：耕地集约化管理，二维问题升维解决
