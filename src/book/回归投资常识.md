## 二、具有中国特色的美林时钟

> 1. 时钟不是顺序转动的，甚至可能倒退
> 
> 2. 盯住政策，知道当前处于什么周期！！！
> 
> 3. 政策也会不坚定，难

### 三个指标

| 指标  | 类型   |
| --- | ---- |
| 政策  | 先行指标 |
| 经济  | 同步指标 |
| 通胀  | 滞后指标 |

政策：喊话、资金供给（银行体系）

经济：资金需求（银行体系）、企业业绩改善

通胀：关注经济会议怎么说

### 周期

|        | 1.增速放缓（初期） | 2.增速放缓（后期） | 3.复苏（初期） | 4.复苏（后期）  | 5.过热      | 6.滞涨    |
| ------ | ---------- | ---------- | -------- | --------- | --------- | ------- |
| **政策** | 收紧↑        | 宽松↑        | 宽松↑↑     | 中性        | 收紧↑       | 收紧↑↑    |
| **经济** | ↓          | ↓          | ↑        | ↑         | ↑         | ↓       |
| **通胀** | ↓          | ↓          | ↓↓↓触底    | ↑         | ↑         | ↑↑↑触顶   |
| 利好     | 债券         | 债券、一级火箭    | 二级火箭     | 二级火箭、大宗商品 | 三级火箭、大宗商品 | 大宗商品、现金 |

## 三、风格轮动

> 熊牛不清时

|      | 高光时刻           | 解释          |
| ---- | -------------- | ----------- |
| 大盘成长 | 外资↑，社融↑，信用利差↑  |             |
| 大盘价值 | 社融↑↑，政策↑，信用利差↑ |             |
| 小盘成长 | 社融触底回暖，经济增速一般  | 资金不足，小盘容易推高 |
| 小盘价值 | 滞涨             | 投价值本质上还是防守  |

信用利差：需要更高的收益率补偿信用风险

### 三大轮动策略

|      | 场景  | 指标                      | 表现周期          | 板块                       |
| ---- | --- | ----------------------- | ------------- | ------------------------ |
| 红利   | 弱衰退 | 高股息率                    | 下跌初期<br/>下跌末期 | 金融                       |
| GARP | 强复苏 | PB-ROE在均线以下（估值 / 净资产收益） | 复苏初期          | 消费（用沪深300或A500替代，因为消费降级） |
| 高景气  | 弱复苏 | 高估值、高成长                 | 复苏后期          | 创业板、科创50                 |

**注：下跌中期为泥沙俱下，强衰退，改做资产轮动**
